# Calendario de seguridad y EPP

Agenda interactiva con fechas de Argentina e internacionales, fuentes y propuestas de campaña.

## Publicar en GitHub Pages
1. Crear un repositorio público llamado calendario-seguridad-epp.
2. Subir los archivos de este paquete a la raíz del repositorio (no el ZIP).
3. En Settings > Pages, seleccionar Deploy from a branch.
4. Seleccionar main y / (root), y guardar.
5. Compartir la dirección que indique GitHub Pages.

El PDF corresponde a 2026. Las fechas móviles se ajustan en la web; el Día del Ruido requiere confirmación en futuras ediciones.
